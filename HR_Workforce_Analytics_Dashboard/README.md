# HR Workforce Analytics Dashboard

Synthetic HR analytics portfolio project for Microsoft Power BI.

Files:
- Dataset/HR_Employee_Dataset.csv
- Dataset/HR_Workforce_Analytics_Data.xlsx
- PowerBI/DAX_Measures.txt
- PowerBI/PowerBI_Build_Guide.md

The Excel workbook is already separated into fact and dimension tables so it can be imported into Power BI and modelled as a star schema.
